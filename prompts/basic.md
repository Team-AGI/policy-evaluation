제공된 MCP 보안 관리 정책의 본문을 응집성, 사실적 일관성, 유창성 및 관련성에 따라 평가하라. 아래의 상세 평가 절차와 제공된 기준 정의 및 채점 조건을 적용하라.
1. 검토 범위와 자료
요청에 제시된 정책 ID의 본문 하나를 평가하라. 관련 정책은 공통 용어, 책임, 적용 조건과 조치의 관계를 확인하는 데 참조하고, 근거 자료는 연결된 보안 위험 분석 결과와 보안 요구사항으로 한정하라. 각 자료의 ID와 해당 내용을 확인하라.
2. 정책의 목적과 적용 조건 확인
정책과 근거 자료에서 다루는 문제와 보안 목표를 확인하라. 누가 어떤 대상에 어떤 상황에서 무엇을 수행하거나 허용 또는 금지하는지, 승인이 필요한 경우 그 권한이 누구에게 있는지 파악하라. 예외를 허용한다면 적용 범위와 승인 근거를 확인하라. 관련 정책에 정해진 공통 내용도 함께 참조하라.
3. 응집성 검토
정책의 목적, 적용 조건과 요구하는 조치가 논리적으로 연결되는지 검토하라. 문장 간 연결이 끊기거나 같은 대상과 조건에서 함께 준수하기 어려운 요구가 있는지 확인하라. 관련 정책과 비교할 때는 적용 대상과 조건의 차이를 먼저 확인하고, 실제로 충돌하는 경우 해당 정책 ID, 조건과 조치를 기록하라.
4. 사실적 일관성 검토
정책의 기술적 설명과 전제를 보안 위험 분석 결과 및 보안 요구사항의 해당 내용과 대조하라. 위험의 원인이나 요구사항의 의미를 바꾸거나 근거 자료와 상충하는 설명이 있는지 확인하라. 오류를 지적하면 상충하는 내용과 근거 ID를 제시하라. 근거 자료가 제공되지 않아 확인할 수 없는 상태와, 제공된 근거에 비추어 설명이 잘못된 상태를 구분하라.
5. 유창성 검토
용어와 문장의 의미를 일관되게 이해할 수 있는지 검토하라. 주체, 대상, 지시어, 조건과 예외의 연결이 불분명하여 서로 다른 행동으로 해석될 수 있는 표현을 확인하라. 문제가 있으면 해당 정책 ID와 표현의 문제를 간략히 설명하고, 어떤 해석 차이가 생기는지 작성하라. 내용 자체의 누락은 관련성에서 구분하여 다루라.
6. 관련성 검토
해당 정책이 담당하는 위험 대응과 요구사항이 포함되어 있는지, 정책 목적과 무관한 내용이 있는지 검토하라. 정책 준수에 필요한 대상, 조건, 책임, 조치와 해당되는 예외 또는 승인 내용이 충분한지 확인하라. 누락을 지적하기 전에 관련 정책에 이미 정해져 있는지 확인하라. 누락된 내용, 그 내용이 필요한 위험 ID 또는 요구사항 ID와 관련 정책으로도 보완되지 않는 이유를 기록하라.
7. 채점과 응답 작성
검토 결과를 바탕으로 네 기준에 각각 1~5점의 정수를 부여하라. 점수가 높을수록 해당 기준을 충족하는 것으로 평가하라. 기준별 판단에는 충족 사항 또는 확인된 문제, 관련 ID와 대조 결과를 포함하라. 기준 간 점수를 서로 대신하지 말고 각 기준의 정의와 채점 조건을 적용하라.
자료 부족으로 해당 기준을 판단할 수 없으면 점수를 null로 표시하고, 부족한 자료와 사유를 작성하라. 자료가 부족하다는 이유만으로 정책에 오류나 누락이 있다고 단정하지 말라. 보완 사항은 확인된 문제와 연결하고, 기존 자료에 없는 개선 제안은 제안임을 표시하라.
응답은 policy_id, scores, reasons, improvements, missing_reasons를 포함한 공통 JSON 형식으로만 작성하라. 기준명은 coherence, consistency, fluency, relevance로 하라. reasons에는 judgment, policy_ids, risk_ids, requirement_ids, comparison을 작성하라. 정책과 근거 자료의 원문은 반복 출력하지 말고, 판단 근거와 대조 결과를 간략히 요약하라.
