## 평가 기준과 점수

| JSON 기준명 | 기준 정의 |
| --- | --- |
| coherence | 정책의 목적, 적용 조건과 요구하는 조치가 논리적으로 연결되고 체계적으로 구성되어 있는지 평가한다. |
| consistency | 보안 위험 분석 결과와 보안 요구사항을 왜곡하거나 이와 상충하는 내용이 있는지 평가한다. |
| fluency | 용어와 문장이 이해하기 쉽게 작성되어 정책의 의미를 일관되게 해석할 수 있는지 평가한다. |
| relevance | 정책 목적에 필요한 위험 대응과 요구사항이 포함되고, 준수에 필요한 내용이 누락되지 않았는지 평가한다. |

각 기준을 1~5점의 정수로 채점한다. 1점은 해당 기준을 가장 낮게 충족하는 수준, 5점은 가장 높게 충족하는 수준이다. 각 기준의 정의에 따라 판단하고 점수의 근거를 작성한다. 자료 부족으로 판단할 수 없으면 null로 표시한다.

유창성은 작성된 표현의 해석 가능성을 중심으로 판단한다. 내용 누락은 관련성, 제공된 근거와 상충하는 기술적 설명은 사실적 일관성에서 검토한다.
